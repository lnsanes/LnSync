LnSync client mods
==================

Do not double-click jars.

Recommended (works on Forge / NeoForge / Fabric / Quilt):
  mods\lnsync.jar
  (same file as lnsync-universal.jar)

Optional single-loader jars if you prefer a slimmer package:
  lnsync-forge.jar / lnsync-neoforge.jar / lnsync-fabric.jar / lnsync-quilt.jar

Also copy lnsync.toml.example to the instance root as lnsync.toml
(update_server / update_token), then launch the game normally.

Log: instance logs\lnsync.log

中文：直接用通用版 lnsync.jar 放进 mods 即可（四加载器都能认）；
实例根目录放 lnsync.toml，用启动器开游戏。
